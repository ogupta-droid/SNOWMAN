# SNOWMAN
## How to Play
- Choose a difficulty: easy, medium, or hard
- Choose a language: English, Spanish, or French
- Guess letters to reveal the hidden word
- You have a limited number of incorrect guesses
- Guess the word before you run out of guesses to win

## Features
- Three difficulty levels
- Three language options
- Points system
- Hint option
- Whole-word guessing option

### Difficulty Levels
- Easy: Short, common words
- Medium: Longer words
- Hard: Long, challenging words


## Code Highlights
- Uses functions to organize different parts of the game
- Uses `random.choice()` to select a random word
- Uses lists to store word banks and guessed letters
- Uses loops to keep the game running until the player wins or loses
- Uses `if` statements to check guesses and difficulty
- Uses `try/except` to handle invalid inputs
- Updates and displays the hidden word as letters are guessed
